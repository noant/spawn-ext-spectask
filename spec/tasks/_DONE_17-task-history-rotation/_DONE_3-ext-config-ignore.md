# Step 3: Extension config — agent-ignore, files entry, version bump

Status: Done
Suggested model: glm-5.3-flash
Used model: glm-5.3-flash

## Goal
Register the script and the history ignore in `extsrc/config.yaml`, bump the extension version, refresh generated files.

## Approach
Edit `extsrc/config.yaml` (ignore + `files:` entry), bump `version` with `spawn-ext-increment-version`, then run `spawn extension check . --strict`; regenerate the local extension copy with `spawn refresh` (fallback: `spawn extension add .` if refresh does not regenerate ignores) and verify `.cursorignore` / `.gitignore`.

## Affected files
- `extsrc/config.yaml` — keys `agent-ignore`, `files`, `version`
- `.cursorignore` / `.gitignore` — regenerated by `spawn refresh` (verify only)

## Code changes (before / after)

### `extsrc/config.yaml` — `agent-ignore` (add one glob)

**Before**
```yaml
agent-ignore:
  - spec/seeds/_DONE_*.md
  - spec/tasks/**/_DONE_*/_DONE_*.md
  - spec/.config/**
```
History folder not ignored; agents would index archived tasks.

**After**
```yaml
agent-ignore:
  - spec/seeds/_DONE_*.md
  - spec/tasks/**/_DONE_*/_DONE_*.md
  - spec/tasks/__history/**
  - spec/.config/**
```
`spec/tasks/__history/**` is skipped by agents; stays tracked in git (NOT added to `git-ignore`).

### `extsrc/config.yaml` — `files` (register the shipped script)

**Before**
```yaml
files:
  spec/main.md:
    description: "Spec-Tasks methodology — folder structure, eight-step process, overview template."
    mode: static
    globalRead: auto
    localRead: required
```
No `spec/scripts/rotate_history.py` entry.

**After**
```yaml
files:
  spec/scripts/rotate_history.py:
    description: "History rotation script — moves done task folders older than the newest 10 into spec/tasks/__history/ (Step 8)."
    mode: static
    globalRead: no
    localRead: no
  spec/main.md:
    description: "Spec-Tasks methodology — folder structure, eight-step process, overview template."
    mode: static
    globalRead: auto
    localRead: required
```
The script is deployed to consumer repos by `spawn extension add` / re-adding the extension. Read flags are `no`/`no` (default): the script is executed, not read into agent context; under `--strict` the `description` is then optional but kept for self-documentation.

### `extsrc/config.yaml` — `version`

**Before**
```yaml
version: "1.26.0"
```
**After**
```yaml
version: "1.27.0"
```
Bumped via `spawn-ext-increment-version` (substantive packaging change: new ignore + `files:` entry).

## Additional actions
- `spawn extension check . --strict` — must pass.
- `spawn refresh` (fallback `spawn extension add .`) — then verify `.cursorignore` contains `spec/tasks/__history/**` inside the `spawn:ext` block and `.gitignore` gained no new entry.
